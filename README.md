# 📊 Smart Data Cleaning & Reporting Automation System

## 📌 Project Overview

This project automates the process of:

- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Data Visualization
- Automated Reporting

Built using:

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

---

## 🚀 Features

✅ Upload CSV files  
✅ Automatic data cleaning  
✅ Handle missing values  
✅ Remove duplicates  
✅ Generate statistical summary  
✅ Create visual reports  
✅ Download cleaned dataset
